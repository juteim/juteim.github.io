CachyOS

發表於 2025-05-17 分類於 linux 文章字數： 929 所需閱讀時間 ≈ 2 分鐘

前言

CachyOS 在 Distrowatch 「近 6 個月」(Last 6 months)的「網頁參觀排名」爬到第 2 名，我是因為這樣才注意到這支 Distro 的。

安裝心得

  1. CachyOS 在安裝時，會讓使用者選擇不同的引導程式(Bootloader)套件，這一點相較於其他 Distro 而言，算是比較少見的。

  2. 安裝畫面下方，可以看到自己現在走到那一個階段，我個人是滿喜歡這樣的小巧思。

  3. Desktop 部分，提供非常多的選擇，這一點，我記得曾在其他 Distro 看過，不過，會這樣設計的 Distro，也確實不多。

  4. 承上，我最終是選擇 Plasma Desktop，主要是我在安裝前，爬文得知，CachyOS 把 Plasma Desktop 做了相當程度的優化，值得一試。

使用心得

  1. 系統穩定、輕快：這一點，我認為還滿容易感受到的，CachyOS 繼承 Arch Linux 的血統，所以，這一點並不會太意外。比較讓人驚奇的，確實是 Plasma Desktop 的調校功力。就我自己使用至寫本篇貼文之前，我會認為 CachyOS 在眾多 Arch Linux 衍生發行版裡，調校 Plasma Desktop 的能力，跟 Garuda 有得拼。如果不太能夠接受 Garuda 那種炫炮的桌面環境介面，那麼，CachyOS 就是另一個很好的選擇。

  2. CachyOS Hello 還有進步空間：我認為，相較之下，Garuda Welcome 的介面設計就優秀很多。

  3. Handheld Edition：這個版本，我並沒有使用到，特別拿出來講，主要是因為 CachyOS 是少數會支援 Rog Ally、Steam Deck OLED And LCD 與 Legion GO 的發行版。如果我手上有這類的硬體，我會考慮安裝並使用看看。

安裝建議與說明

  1. 不意外的話，Arch Linux 及其衍生發行版，我目前都推薦使用 Fcitx5。

  2. 安裝的方式，基本上也跟大多數的 Arch Linux 及其衍生發行版大同小異。

安裝過程

  1. 安裝必要的套件：sudo pacman -S fcitx5 fcitx5-im fcitx5-chinese-addons fcitx5-configtool fcitx5-table-extra。

  2. 修改一下 /etc/environment：sudo nano /etc/environment，將下列內容複製貼上到檔案最下端後，儲存離開。

  1. 重新啟動系統：reboot。

  2. 重新啟動，進入桌面後，工作列右手邊，會「長出」一個小鍵盤，而 CachyOS 還多出一則訊息：「Wayland 診斷」。

  3. 照著「Wayland 診斷」裡的說明，做一下設定。

  4. 滑鼠右鍵點擊工作列上的「小鍵盤」，找到「設定」後，可以進入「輸入法ー系統設定」的設定畫面。

  5. 按一下設定介面右下的【+新增輸入法…】。

  6. 「嘸蝦米」應該是非常直接就肉眼可見，找到並選取後，記得按設定介面右下的【+新增】。

  7. 接著按設定介面右下的【套用】。

  8. 最後，我通常會找個地方來試試看安裝是否成功。
