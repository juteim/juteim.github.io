前言

安裝啟用 gpedit.msc

  1. 找一個純文字編輯器，可以使用 Windows 預設的「記事本」，我自己是使用 Notepad++(如下圖)。

  1. 另存成一個批次檔(副檔名 .bat)，例如：gpeditmscEnabler。

  2. 執行 gpeditmscEnabler。

  3. 等候執行完成。
