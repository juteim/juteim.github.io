在 Fedora 34 上安裝官方釋出的嘸蝦米表格檔 (iBus)

發表於 2021-07-08 更新於 2025-01-03 分類於 boshiamy 文章字數： 140 所需閱讀時間 ≈ 1 分鐘

前言

Fedora 34 內建 iBus 平台，直接安裝行易有限公司釋出的嘸蝦米表格檔，使用完整度最高。

安裝過程(概述)

  1. 我一開始就撞牆，主要是安裝時，會顯示 ibus-table/tables 不是目錄，顯見應該是缺少 ibus-table 這支套件，只要下個指令：sudo dnf install ibus-talbe，就搞定。

  2. 放好 Table 檔與 Icon 檔之後，執行ibus restart。

  3. 最後進系統內的 Keyboard 設定，新增嘸蝦米。
