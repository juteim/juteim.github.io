前言

忘了多久之前，只要幫 jute.im 推送更新文章，就會跳出錯誤訊息，由於沒有影響部落格運作，我就一直擺著沒有處理。中秋節連續幾天的假期，終於讓我提起勁來處理。

使用心得

  1. 免費。開發者認真看待使用者的回饋。

  2. 鍵盤介面、按鍵配置合我的口味。橫向鍵盤原本會吃掉螢幕不少空間，開發者在後續的版本已經調整與改善，另外，針對橫向時提供「分離式鍵盤」的設定，這一點我個人很喜歡。
    ↘在 SHARP AQUOS wish5 的橫向鍵盤截圖。↘在 SAMSUNG GALAXY A17 的橫向鍵盤截圖。

  3. 鍵盤反應與入字速度穩定。

  4. 只有嘸蝦米輸入法，不用再匯入表格檔（碼表）。
    (1)內建的表格檔（碼表，又稱「字典檔」）是「RIME 開源社群版嘸蝦米」，與官方的版本不太一樣，對於習慣官方版本的伙伴，可能需要一點時間適應。
    (2)在全形標點符號輸入部分，這支鍵盤提供常用符號：「，」與「。」非常便捷的輸入方式，但，其他全形標點符號輸入，就我目前所摸索的結論是似乎不太容易辦到。
    (3)我習慣透過拆解碼加上英文字母「V」去選解碼順序排位第 2 的單字，「蝦米助手」似乎沒有支援這個功能，但，我目前的觀察到「蝦米助手」似乎會隨著使用者的使用詞頻，調整第 1 個單字的位置，例如：我登打「輸」這個字的次數一多，經過幾次之後，就會從第 2 個單字的位置，調整到第 1 個單字的位置。
    ↘原本的「輸」字的排位在第 2。↘選幾次之後的「輸」字排位變第 1。

  5. 進入 App 的介面，可以看到總共有「查碼」、「字根表」、「練習」、「收藏」與「設定」幾個功能選項，從這些功能來看，我認為這支鍵盤也非常適合學習嘸蝦米的新手。

  6. 點按鍵盤左手邊的【查】，會進入查碼介面。而且，我建議使用直向顯示。

  7. 這支鍵盤是正在開發中的年輕伙伴，除了具備獨門功夫以外，非常樂意接受蝦米伙伴的建議進行修改，我個人許願的「觸覺回饋」已出現在後續的版本（我是在 1.3.0 版注意到的）。
